通过 WSL2 和 vs Code 搭建 Java 开发环境

1. 准备工作：启用 WSL2 如果你尚未安装 WSL2，请按以下步骤操作： 以管理员身份打开 PowerShell。 运行安装命令（默认安装 Ubuntu）： wsl --install 重启计算机。 重启后，根据提示设置 Linux 的用户名和密码。 2. 安装并配置 VS Code 在 Windows 上下载并安装 Visual Studio Code。 打开 VS Code，进入插件市场（Ctrl+Shift+X），搜索并安装 WSL 扩展插件。 点击 VS Code 左下角的蓝色角标 ><，选择 Connect to WSL。连接成功后，左下角会显示 WSL: Ubuntu（或你安装的发行版名称）。 3. 在 WSL2 中安装 Java (JDK) 在 WSL 终端中，我们推荐使用包管理器安装 JDK。 更新系统软件包 sudo apt update && sudo apt upgrade -y 安装 JDK 你可以选择安装常用的 OpenJDK（例如 Java 17 或 Java 21）： # 安装 OpenJDK 17 sudo apt install openjdk-17-jdk -y 验证安装 java -version javac -version 4. 配置 Java 环境变量 通常通过 apt 安装的 JDK 会自动配置，但为了确保工具链正常，建议手动检查环境变量。 ...
